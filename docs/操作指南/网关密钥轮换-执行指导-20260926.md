### 1.2 处置原则（为什么必须轮换而非「改文档」）

1. **git 历史不可篡改假设**：旧键存在于历史提交，任何拿到仓库读权限（含 fork/clone/CI 缓存）的主体均可回溯提取；
2. **泄露面等价原则**：无法证明「没人看过」→ 一律按已泄露处理（与 NIST SP 800-57 密钥生命周期纪律一致）；
3. **最小窗口原则**：轮换存在双键过渡窗口（§四），过渡期越长风险敞口越大——建议 **24 小时内完成收敛**。

## 二、资产与影响面分析

### 2.1 真实拓扑（分析修正）

> ⚠️ **重要认知修正**：此前表述「SSH 至 ECS 替换 Traefik/Nginx 的 ADMIN_API_KEYS」**不准确**。经 [API全链路闭环文档](../架构与部署/API全链路闭环文档.md) 与 [API认证使用指南](./API认证使用指南.md) 核实，API Key 并不存在于 Traefik/Nginx 配置中，而是存放于**网关应用层 `.env`**：

```
公网客户端
    ↓ https
yyc3-33 ECS：Traefik 边缘反代（api.0379.world）
    │   职责：TLS 终结 / rate-limit / fail2ban / 安全头 —— ❌ 无任何 API Key
    ↓ 反代
yyc3-45 NAS：0379-World 网关（FastAPI，NAS:8000，公网唯一计算实例）
    │   ✅ 密钥真实落点：/volume1/docker/yyc3-gateway/.env
    │      ├─ API_KEYS        （业务/推理面，X-API-Key 头）
    │      └─ ADMIN_API_KEYS  （管理面 /v1/admin/** + H3 runner 密钥同源）
    ↓ 静态代理
Nginx（/h3-dashboard/ 面板静态站点）
        职责：静态文件 + 路径代理 —— H3 面板键（READONLY）的校验层之一 ⚠️ 落点待现场确认
```

### 2.2 需换键的落点清单

| # | 落点 | 变量/机制 | 是否需替换 | 依据 |
| - | ---- | --------- | ---------- | ---- |
| L1 | NAS 网关 `.env`（`/volume1/docker/yyc3-gateway/.env`，路径待现场确认） | `ADMIN_API_KEYS`（含 H3 `H3_VIDEO_RUNNER_KEY` 同源键） | **是** | 管理面键；runner 依赖它 claim 任务 |
| L2 | NAS 网关 `.env` | `API_KEYS`（业务键） | 视情况 | 若业务键与泄露键同值则换；无泄露记录则可暂缓（标注待确认） |
| L3 | H3 面板公网入口（doc 09 鉴权层，Nginx 或网关中间件） | `API_KEY_ADMIN` / `API_KEY_READONLY` | **是** | 泄露键的直接宿主 |
| L4 | ECS Traefik | — | 否（无键） | 仅边缘反代；确认无 `X-API-Key` 类静态配置残留即可 |
| L5 | H3 Agent 网关 claim（`AGENT_CLAIM_SECRET`） | HMAC 共享密钥 | 否（独立密钥，未泄露） | 2026-09-26 新生成，与本次轮换无耦合 |

## 四、执行指导（五阶段零中断轮换）

> 时间预算：操作约 30 分钟 + 过渡窗口（客户端切换）建议 ≤24h。

### Phase 0 准备与备份（NAS 上）

```bash
# 0.1 登录 NAS 并定位网关 compose 目录（ENV_FILE 按实际路径调整，通常为 gateway compose 同目录）
ENV_FILE="/volume1/docker/yyc3-gateway/.env"      # ⚠️ 待现场确认：find /volume1/docker -name '.env' -path '*gateway*'

# 0.2 确认现状（只看键名与键数量，不回显键值）
grep -c '^ADMIN_API_KEYS=' "$ENV_FILE"            # 期望 1
grep -oE '^[A-Z_]+=' "$ENV_FILE" | sort           # 变量清单（确认 API_KEYS/ADMIN_API_KEYS 存在）

# 0.3 双备份（带时间戳；sed 的 .bak 不够可靠，显式备份）
cp -p "$ENV_FILE" "$ENV_FILE.bak-rotate-$(date +%Y%m%d-%H%M%S)"
```

### Phase 1 阶段①双写（旧,新 并存——零中断窗口开启）

优先使用内置脚本（双写守卫 + 自动备份 + 预检）：

```bash

bash core/scripts/rotate_admin_key.sh status     # 先看当前态
bash core/scripts/rotate_admin_key.sh stage1     # ADMIN_API_KEYS=旧KEY,新KEY 并存 → 重启网关
```

脚本不可用时的手工等价：

```bash
NEW_ADMIN="yyc3_<从 rotation env 文件读取 API_KEY_ADMIN 值>"   # 不要写进 shell 历史可用 read -s
read -s -p "Paste NEW ADMIN KEY: " NEW_ADMIN && echo

if grep -q '^ADMIN_API_KEYS=' "$ENV_FILE"; then
    sed -i.bak "s|^ADMIN_API_KEYS=.*|ADMIN_API_KEYS=旧KEY,${NEW_ADMIN}|" "$ENV_FILE"
fi
grep -c '^ADMIN_API_KEYS=' "$ENV_FILE"           # 期望仍为 1（防重复行）
grep -o '^ADMIN_API_KEYS=' "$ENV_FILE"           # 不回显值，仅确认行存在

# 立即双验（旧新两枚都应 200）
curl -s -o /dev/null -w 'old:%{http_code}\n' -H "X-API-Key: <旧ADMIN键>" https://api.0379.world/v1/admin/virtual-keys
```

| 场景 | 动作 |

## 九、Phase 0 勘察实证（2026-09-26 执行 · 只读，未做任何变更）

> 本节为实际 SSH 勘察结果，**修正本文档 §二 的拓扑推测**，并**改变处置建议**。

### 9.1 真实拓扑（实证）

| 层 | 实证 | 勘误 |
| -- | ---- | ---- |
| ECS yyc3-33 | 仅 `docker-traefik-1`（80/443）；配置 `/root/0379-world/traefik/{traefik,dynamic}.yml`；`api.0379.world → http://100.65.172.88:8000` | ✅ 无密钥，此前判断正确 |
| NAS yyc3-45 | 容器 `0379-world-gateway-1`（uvicorn app.main:app，bridge 模式经 docker-proxy 发布 8000）；**无独立 Nginx 容器**（面板由网关一体服务） | ⚠️ 修正：「Nginx 层持键」不存在，L3 收敛点即网关 `.env` |
| **ENV_FILE** | **`/Volume2/yyc3-33/.env`**（600，属主 YYC3） | ⚠️ 修正：非 `/volume1/docker/...`，NAS 数据卷为 `/Volume1/2/3` 大写 |
| 容器管理 | NAS **无 docker CLI**，经 `/var/run/docker.sock` API 操作；compose 工程 `/Volume2/yyc3-33/deploy/nas/docker-compose.nas.yml` | 重启：`curl --unix-socket /var/run/docker.sock -X POST http://localhost/containers/<id>/restart` |
| 部署桥 | NAS `auto-deploy.sh` 监听 git 新提交 → `compose up -d --build gateway`，**不同步 .env**（直接改 .env 安全） | 方式 B 手工重启可用 sock API 等价替代 |
| 变量实测 | `ADMIN_API_KEYS`：1 键 ×41 字符（符合 `sk-admin-<32hex>` 生成器）；`API_KEYS`：1 键 ×**20 字符（偏短）** | — |

### 9.2 关键结论：泄露键 ≠ 生产真实键

逐值哈希比对（仅输出 verdict，不回显）：

| 比对 | 结果 |
| -- | ---- |
| doc09 泄露 `API_KEY_ADMIN`（26 字符） vs 现网 `ADMIN_API_KEYS`（41 字符） | **不匹配** |
