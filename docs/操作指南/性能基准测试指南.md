## 🔧 测试工具

### k6

**优势**:
- ✅ Go 语言编写，性能优秀
- ✅ JavaScript 脚本，易于编写
- ✅ 内置多种测试场景
- ✅ 支持 CI/CD 集成
- ✅ 丰富的指标输出

**安装**:
```bash
# macOS
brew install k6

# Linux
sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys C5AD17C747E3415A3642D57D77C6C491D6AC1D69
echo "deb https://dl.k6.io/deb stable main" | sudo tee /etc/apt/sources.list.d/k6.list
sudo apt-get update
sudo apt-get install k6

# Docker
docker pull loadimpact/k6
```

### Locust

**优势**:
- ✅ Python 编写，易于扩展
- ✅ Web UI 界面
- ✅ 分布式测试支持
- ✅ 实时监控
- ✅ 插件生态丰富

**安装**:
```bash
# pip 安装
pip install locust

# 验证安装
locust --version
```

## 📝 测试场景

### 1. 烟雾测试（Smoke Test）

**目的**: 验证系统基本功能  
**配置**:
- 并发用户: 10
- 持续时间: 5 分钟
- 阈值: P95 < 500ms, 错误率 < 5%

**执行**:
```bash
k6 run --vus 10 --duration 5m tests/performance/load-test.js
```

---

### 2. 负载测试（Load Test）

**目的**: 验证系统在正常负载下的性能  
**配置**:
- 并发用户: 100
- 持续时间: 10 分钟
- 阈值: P95 < 500ms, 错误率 < 5%

**执行**:
```bash
k6 run --vus 100 --duration 10m tests/performance/load-test.js
```

---

### 3. 压力测试（Stress Test）

**目的**: 找到系统的性能极限  
**配置**:
- 并发用户: 300
- 持续时间: 15 分钟
- 阈值: P95 < 1000ms, 错误率 < 10%

**执行**:
```bash
k6 run --vus 300 --duration 15m tests/performance/load-test.js
```

---

### 4. 峰值测试（Spike Test）

**目的**: 验证系统处理突发流量的能力  
**配置**:
- 并发用户: 0 → 100 → 0
- 持续时间: 2 分钟
- 阈值: P95 < 1000ms, 错误率 < 10%

**执行**:
```bash
k6 run tests/performance/comprehensive-test.js
```

---

### 5. 浸泡测试（Soak Test）

**目的**: 验证系统长时间运行的稳定性  
**配置**:
- 并发用户: 50
- 持续时间: 1 小时
- 阈值: P95 < 500ms, 错误率 < 5%

**执行**:
```bash
k6 run --vus 50 --duration 1h tests/performance/load-test.js
```

## 🎯 性能指标

### 关键指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| **响应时间** | 请求处理时间 | P95 < 500ms |
| **吞吐量** | 每秒处理请求数 | > 100 req/s |
| **错误率** | 失败请求比例 | < 5% |
| **并发用户** | 同时在线用户数 | > 100 |
| **CPU 使用率** | 服务器 CPU 占用 | < 80% |
| **内存使用率** | 服务器内存占用 | < 80% |

### 性能等级

| 等级 | P95 响应时间 | 错误率 | 吞吐量 |
|------|-------------|--------|--------|
| **优秀** | < 200ms | < 1% | > 200 req/s |
| **良好** | < 500ms | < 5% | > 100 req/s |
| **一般** | < 1000ms | < 10% | > 50 req/s |
| **较差** | < 2000ms | < 20% | > 20 req/s |
| **失败** | > 2000ms | > 20% | < 20 req/s |

## 📊 测试执行

### 使用脚本执行

```bash
# 执行烟雾测试
./scripts/run-performance-test.sh https://api.0379.world yyc3_api_key_test_2026 smoke

# 执行负载测试
./scripts/run-performance-test.sh https://api.0379.world yyc3_api_key_test_2026 load

# 执行压力测试
./scripts/run-performance-test.sh https://api.0379.world yyc3_api_key_test_2026 stress

# 执行综合测试
./scripts/run-performance-test.sh https://api.0379.world yyc3_api_key_test_2026 comprehensive
```

### 手动执行

#### k6 测试

```bash
# 基础测试
k6 run tests/performance/load-test.js

# 自定义参数
k6 run \
  --vus 100 \
  --duration 10m \
  --out json=results.json \
  tests/performance/load-test.js

# 分布式测试
k6 run --out influxdb=http://localhost:8086/k6 tests/performance/load-test.js
```

#### Locust 测试

```bash
# Web UI 模式
locust -f tests/performance/locust_test.py --host https://api.0379.world

# 无头模式
locust \
  -f tests/performance/locust_test.py \
  --host https://api.0379.world \
  --users 100 \
  --spawn-rate 10 \
  --run-time 5m \
  --headless \
  --html results.html

# 分布式测试
locust -f tests/performance/locust_test.py --master
locust -f tests/performance/locust_test.py --worker --master-host=localhost
```

## 🚨 性能优化建议

### 1. 响应时间优化

**问题**: 响应时间过长（P95 > 500ms）

**解决方案**:
- ✅ 数据库查询优化（添加索引）
- ✅ 缓存热点数据（Redis）
- ✅ 异步处理耗时操作
- ✅ CDN 加速静态资源

### 2. 吞吐量优化

**问题**: 吞吐量不足（< 100 req/s）

**解决方案**:
- ✅ 增加服务器资源
- ✅ 负载均衡配置
- ✅ 连接池优化
- ✅ 并发处理优化

### 3. 错误率优化

**问题**: 错误率过高（> 5%）

**解决方案**:
- ✅ 检查日志定位错误
- ✅ 增加重试机制
- ✅ 熔断降级策略
- ✅ 资源扩容
