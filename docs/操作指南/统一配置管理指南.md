## 📊 配置管理架构

```
┌─────────────────────────────────────────────────────────────┐
│                    统一配置管理架构                           │
└─────────────────────────────────────────────────────────────┘

┌──────────────┐
│  Git 仓库     │  ← 配置版本控制
│  config/     │
└──────────────┘
       │
       │ git pull
       ▼
┌──────────────┐
│  配置服务器   │  ← 集中管理 (yyc3-33)
│  /opt/yyc3/  │
│  config/     │
└──────────────┘
       │
       │ rsync / SSH
       ├──────────┬──────────┬──────────┐
       ▼          ▼          ▼          ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ yyc3-22  │ │ yyc3-33  │ │ yyc3-45  │ │ yyc3-77  │
│ 开发机    │ │ 生产机    │ │ 存储机    │ │ 测试机    │
│ .env     │ │ .env     │ │ .env     │ │ .env     │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

## 📁 配置文件结构

```
config/
├── .env.common              # 通用配置（所有节点共享）
├── .env.production          # 生产环境配置
├── .env.development         # 开发环境配置
├── nodes/                   # 节点特定配置
│   ├── yyc3-22/
│   │   └── .env            # yyc3-22 节点配置
│   ├── yyc3-33/
│   │   └── .env            # yyc3-33 节点配置
│   ├── yyc3-45/
│   │   └── .env            # yyc3-45 节点配置
│   └── yyc3-77/
│       └── .env            # yyc3-77 节点配置
├── postgresql/              # PostgreSQL 配置
│   ├── master/
│   │   ├── postgresql.conf
│   │   └── pg_hba.conf
│   └── slave/
│       ├── postgresql.conf
│       └── recovery.conf
└── templates/               # 配置模板
    ├── .env.template
    └── docker-compose.template.yml
```

## 🔧 配置层级

### 层级 1: 通用配置 (`.env.common`)

**适用范围**: 所有节点  
**配置内容**:
- 项目信息
- API 配置
- 安全配置
- 日志配置
- 监控配置
- CORS 配置
- 速率限制

**示例**:
```bash
# 项目信息
PROJECT_NAME=yyc3-api-world
PROJECT_VERSION=1.0.0

# API 配置
API_HOST=0.0.0.0
API_PORT=8000
API_WORKERS=4

# 安全配置
SECRET_KEY=yyc3_secret_key_change_in_production_2026
JWT_ALGORITHM=HS256
```

---

### 层级 2: 环境配置

#### 生产环境 (`.env.production`)

**适用节点**: yyc3-33, yyc3-45  
**配置内容**:
- 生产数据库配置
- 生产 Redis 配置
- AI 模型配置
- 域名配置
- SSL 配置
- 备份配置
- 告警配置

**示例**:
```bash
# 数据库配置
DB_HOST=yyc3-33
DB_PORT=5432
DB_NAME=yyc3_gpt

# 域名配置
DOMAIN=0379.world
API_DOMAIN=api.0379.world

# SSL 配置
SSL_ENABLED=true
SSL_PROVIDER=letsencrypt
```

#### 开发环境 (`.env.development`)

**适用节点**: yyc3-22  
**配置内容**:
- 开发数据库配置
- 开发 Redis 配置
- 调试配置
- 开发工具配置

**示例**:
```bash
# 数据库配置
DB_HOST=yyc3-22
DB_PORT=5433
DB_NAME=yyc3_gpt_dev

# 调试配置
DEBUG=true
LOG_LEVEL=DEBUG
API_DOCS_ENABLED=true
```

---

### 层级 3: 节点配置 (`nodes/<node>/.env`)

**适用范围**: 特定节点  
**配置内容**:
- 节点信息
- 服务端口
- 节点特定配置

**示例 (yyc3-33)**:
```bash
# 节点信息
NODE_NAME=yyc3-33
NODE_ROLE=production_master
NODE_IP=192.168.3.33

# 服务端口
API_PORT=8000
DB_PORT=5432
REDIS_PORT=6379

# 主库配置
IS_MASTER=true
REPLICATION_ENABLED=true
```

## 🔄 配置同步流程

### 自动同步

```bash
# 使用批量同步脚本
./scripts/sync-all-configs.sh
```

**同步步骤**:
1. 拉取最新配置（Git）
2. 同步到各节点（rsync）
3. 验证配置文件

### 手动同步

```bash
# 同步单个节点
./scripts/sync-config.sh yyc3-33

# 验证配置
./scripts/validate-config.sh yyc3-33
```

## 📝 配置更新流程

### 1. 修改配置

```bash
# 编辑配置文件
vim config/.env.common
vim config/nodes/yyc3-33/.env

# 或使用模板
cp config/templates/.env.template config/nodes/new-node/.env
vim config/nodes/new-node/.env
```

### 2. 提交更改

```bash
# 提交到 Git
git add config/
git commit -m "feat: 更新配置"
git push origin main
```

### 3. 同步配置

```bash
# 同步到各节点
./scripts/sync-all-configs.sh
```

### 4. 重启服务

```bash
# 重启单个节点
ssh yyc3-33 "cd /opt/yyc3/yyc3-33 && docker-compose restart"

# 或批量重启
for node in yyc3-22 yyc3-33 yyc3-45 yyc3-77; do
    ssh ${node} "cd /opt/yyc3/${node} && docker-compose restart"
done
```

## 🔐 敏感信息管理

### 方案 1: Git 加密（推荐）

使用 `git-crypt` 加密敏感配置：

```bash
# 安装 git-crypt
brew install git-crypt

# 初始化加密
git-crypt init

# 配置加密文件
echo "config/.secrets/** filter=git-crypt diff=git-crypt" >> .gitattributes
echo "config/nodes/**/.env filter=git-crypt diff=git-crypt" >> .gitattributes

# 添加 GPG 密钥
git-crypt add-gpg-user USER_ID

# 提交加密配置
git add .
git commit -m "feat: 添加加密配置"
git push
```

### 方案 2: 环境变量注入

```bash
# 使用 Docker Secrets
docker secret create db_password ./secrets/db_password.txt

# 在 docker-compose.yml 中引用
services:
  api:
    secrets:
      - db_password
    environment:
      - DB_PASSWORD_FILE=/run/secrets/db_password
```

### 方案 3: HashiCorp Vault

```bash
# 安装 Vault
brew install vault

# 启动 Vault
vault server -dev

# 存储机密
vault kv put secret/yyc3/db password=My151001

# 读取机密
vault kv get -field=password secret/yyc3/db
```

## 📊 配置验证

### 自动验证

```bash
# 验证单个节点
./scripts/validate-config.sh yyc3-33
```

**验证项**:
- ✅ 配置文件存在
- ✅ 必需的环境变量
- ✅ 数据库连接
- ✅ Redis 连接
- ✅ API 服务

### 手动验证

```bash
# 检查配置文件
cat /opt/yyc3/yyc3-33/.env

# 验证环境变量
docker-compose config

# 测试数据库连接
PGPASSWORD=${DB_PASSWORD} psql -h ${DB_HOST} -p ${DB_PORT} -U ${DB_USER} -d ${DB_NAME} -c "SELECT 1;"

# 测试 Redis 连接
redis-cli -h ${REDIS_HOST} -p ${REDIS_PORT} ping
```

## 🚨 故障排查

### 问题 1: 配置同步失败

**可能原因**:
- ❌ Git 仓库连接失败
- ❌ SSH 连接失败
- ❌ 权限不足

**解决方案**:
```bash
# 检查 Git 连接
git remote -v
git pull origin main

# 检查 SSH 连接
ssh yyc3-33 "echo '连接成功'"

# 检查权限
ls -la /opt/yyc3/yyc3-33/
```

### 问题 2: 配置验证失败

**可能原因**:
- ❌ 缺少必需的环境变量
- ❌ 数据库连接失败
- ❌ Redis 连接失败

**解决方案**:
```bash
# 检查环境变量
grep "DB_HOST" /opt/yyc3/yyc3-33/.env

# 测试数据库连接
PGPASSWORD=My151001 psql -h yyc3-33 -p 5432 -U postgres -d yyc3_gpt -c "SELECT 1;"

# 测试 Redis 连接
redis-cli -h yyc3-45 -p 6379 ping
```

### 问题 3: 服务启动失败

**可能原因**:
- ❌ 配置文件格式错误
- ❌ 端口冲突
- ❌ 依赖服务未启动

**解决方案**:
```bash
# 检查配置文件格式
docker-compose config

# 检查端口占用
netstat -tlnp | grep 8000

# 检查依赖服务
docker ps | grep postgres
docker ps | grep redis
```
