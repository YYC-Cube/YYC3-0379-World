# YYC³ 本地运维智能面板 · 开发任务清单与节点目标

> **承接**：《YYC3-本地运维智能面板-全链路设计提示词 v1.0.0》（下称【设计】）。本文档把设计落实为**可逐步执行**的工程任务，遵循「诊断驱动的最小补丁闭环」：每任务产出可验证的增量、先过静态检查与可视化验收，再进入下一任务。
> **实施原则**：技术栈锁定（Next.js 16.3 / React 19 / Tailwind 4 / shadcn / TanStack Query v5 / Zustand v5 / Recharts），dev 端口 3030；数据契约以《05-监控告警与Runbook》为唯一真源，禁止虚构指标/端点。

---

## 总览：阶段划分与里程碑

| 阶段 | 目标 | 交付核心 | 里程碑 |
| ---- | ---- | -------- | ------ |
| **P0** | 骨架 + 总览 + 动效基座 + 离线 | App Shell、导航、Overview、Service Worker、动效令牌系统 | M1 本地可跑通 Overview + 离线浏览 |
| **P1** | 数据源 + 日志 | 数据适配层、实时通道、Data Monitoring、Logs | M2 双数据打通、日志可检索可回放 |
| **P2** | 实时看板 + 告警 + 智能①②④ | Live Board、Alert Center、异常识别、上下文关联 | M3 看板可拖拽、告警闭环、异常高亮+溯源 |
| **P3** | 配置 + 健康 + 智能收口③⑤② | Config、System Status、快捷调用、操作路径提示、布局自适应 | M4 全七页 + 五维智能全量、通过性能门禁 |

> 单任务用  ⬜ 未开始 / 🔄 进行中 / ✅ 已完 / ❌ 阻塞  标记，执行时实时更新。

## P0 · 骨架 · 总览 · 动效基座 · 离线

> 对应【设计】第 2.1/2.2/4.1/4.4/4.6/6 节。

### Task P0-1 创建前端工程与依赖基线
- **输入**：Next.js 16.3 LTS + React 19 + TS strict + Tailwind 4 + pnpm workspace 脚手架；接入 shadcn；安装 TanStack Query/Zustand/Recharts/TanStack Table/zod/date-fns/lucide
- **文件路径**：`apps/panel/`（建议独立包，不与 Token 控制台混布）
- **验收**：`pnpm dev` 在 3030 起服务；shadcn 组件可 Add
- **依赖**：无
- **设计映射**：【设计】§0 技术栈锁 / §7 映射

### Task P0-2 建立状态语义令牌与设计令牌单一真源
- 内容：`app/globals.css` 的 `@theme` 定义 `color/status/{ready,warning,danger,info,neutral}`、间距/圆角/阴影/字体/断点；接入品牌主色
- **验收**：任一组件可用 `bg-status-warning` 等 token；无硬编码状态色
- **依赖**：P0-1
- **设计映射**：【设计】§3.3

### Task P0-3 App Shell（侧边导航 + 顶栏 + 浮层引擎）
- 内容：侧边一级导航（7 项，768 折叠）；顶栏（数据源连接状态聚合点、本地时钟、告警铃铛、Cmd+K 占位）；Toast/Drawer/Modal/CommandMenu 统一弹层
- **验收**：七路由入口可跳、折叠动画达标、未填页面用 EmptyState 占位
- **依赖**：P0-2
- **设计映射**：【设计】§2.1、§3.1、§4.1

### Task P0-4 动效基座（页面过渡 + 组件反馈 + 状态过渡）
- 内容：路由出口入场/退场过渡；按钮/Tooltip/开关反馈；状态色 300ms 平滑过渡；`prefers-reduced-motion` 降级
- **验收**：仅 transform/opacity；过渡 ≤400ms；reduced-motion 有效
- **依赖**：P0-2
- **设计映射**：【设计】§4.1/4.4/4.6

### Task P0-5 Overview 主仪表盘（占位版 + 骨架态）
- 内容：核心 KPI 区、资源健康带、心跳卡、异常速览、快捷操作、迷你时间轴六大模块的布局骨架 + 五态
- **验收**：五态可切换；KPI 卡点击有跳转占位
- **依赖**：P0-3
- **设计映射**：【设计】§2.2、§3.1

### Task P0-6 Service Worker 离线壳 + IndexedDB 快照层
- 内容：SW 缓存静态资源；IndexedDB 快照读写抽象（`snapshot://`）；离线时 UI 切换快照态
- **验收**：断网刷新仍可打开 Overview（快照标注）；无公网请求
- **依赖**：P0-1
- **设计映射**：【设计】§1.2 离线降级 / §6

**P0 里程碑 M1 门禁**：Overview 本地可跑通、离线可浏览、动效基座达标、【设计】§6.1 前 3 项自检通过。

## P1 · 数据源 · 实时通道 · 数据监控 · 日志

> 对应【设计】第 1.2/2.3/2.7/3.2/4.2/5.1 节。

### Task P1-1 数据适配层（DataSource 抽象 + 6 数据源）
- 内容：统一 `DataSource` 接口（Prometheus/Loki/Registry/Redis/Env/System）；内网基址与鉴权（X-API-Key）；离线降级判定
- **验收**：每源返回真实契约字段；不可达时抛「离线」态并回读快照
- **依赖**：P0-6
- **设计映射**：【设计】§1.2

### Task P1-2 实时通道（WebSocket + SSE + 轮询降级）
- 内容：`/ws/monitor` WS 增量；SSE(fetch+ReadableStream，禁 EventSource)；指数退避重连；TanStack Query 轮询降级
- **验收**：三通道切换无数据断层；断线按 1s→2s→4s→…→30s 退避
- **依赖**：P1-1
- **设计映射**：【设计】§3.2

### Task P1-3 指标标注与数据增量动效
- 内容：精度/单位/告警阈值元数据表（对齐 05 §2.2）；数字 count-up、单元格高亮、新行滑入
- **验收**：变化才触发动效；sparkline 降采样
- **依赖**：P1-2、P0-4
- **设计映射**：【设计】§4.2

### Task P1-4 Data Monitoring 数据监控面板
- 内容：模型域/实例域/网关域；分域时间轴联动拖选；metric 下钻与导出
- **验收**：跨域时间轴同步缩放；`error_rate>10%`/`latency>2000ms` 标红
- **依赖**：P1-2
- **设计映射**：【设计】§2.3

### Task P1-5 Logs 日志查询界面
- 内容：LogQL 编辑器（语法高亮+常见片段）；虚拟滚动日志行；崩溃事件回放视图（关键字正则 OR 模板）；范围导出
- **验收**：1000 行滚动流畅（仅渲染可见区）；崩溃关键字命中自动聚卡
- **依赖**：P1-1、P0-3
- **设计映射**：【设计】§2.7、§6 虚拟滚动

### Task P1-6 异常指标识别引擎（智能①基础版）
- 内容：静态阈值 + EWMA 偏差 + z-score + 突变检测；产出 `anomaly{...}` 并挂 Overview 异常速览
- **验收**：能识别并高亮；可忽略/确认写白名单
- **依赖**：P1-2
- **设计映射**：【设计】§5.1

**P1 里程碑 M2 门禁**：双数据（Prometheus/Loki）真实打通、日志可检索可回放、异常可识别高亮。

## P2 · 实时看板 · 告警中心 · 智能④

> 对应【设计】第 2.4/2.5/4.3/4.5/5.1/5.4 节。

### Task P2-1 Live Board 实时指标看板（Grid + 拖拽缩放）
- 内容：多面板网格；拖拽/边缘缩放/叠放 pin；8px 吸附 + 对齐引导线；快照/导出
- **验收**：拖拽 60fps、释放吸附无跳变；暂停离屏 Chart 重绘
- **依赖**：P1-2、P0-4
- **设计映射**：【设计】§2.4、§4.5

### Task P2-2 面板订阅与阈值联动（动效）
- 内容：面板订阅任意 metric/日志流（5s/WS 增量）；阈值越线 → glow/描边/顶栏脉冲（节流 5s）
- **验收**：越线触发且不连续波动画；等待确认前不循环播
- **依赖**：P2-1
- **设计映射**：【设计】§4.3

### Task P2-3 Alert Center 告警中心
- 内容：告警列表三态；规则 CRUD（阈值+级别+P0 自动回滚开关）；分级路由 P0→critical/P1-P2→alerts/P3→info；告警记录时间轴
- **验收**：触发→确认→恢复全生命周期可查；P0 有回滚直达按钮
- **依赖**：P2-2、P1-6
- **设计映射**：【设计】§2.5、05 §2.3

### Task P2-4 事件上下文关联引擎（智能④）
- 内容：异常触发自动聚合 [T-2min,T+30s] 的日志/Registry/告警/canary 事件 →「事件上下文抽屉」；标签匹配 + 时间窗回退
- **验收**：异常/告警详情可展开关联上下文；一键跳 Logs 并自动填 LogQL+时间窗
- **依赖**：P2-3、P1-6
- **设计映射**：【设计】§5.4

**P2 里程碑 M3 门禁**：看板可拖拽持久化、告警规则闭环、异常高亮+一键溯源。

## P3 · 配置 · 系统状态 · 智能收口③⑤②

> 对应【设计】第 2.6/2.8/5.2/5.3/5.5 及【05】SOP-02/04。

### Task P3-1 Config 配置管理模块
- 内容：上游 env 可视化编辑（字段合法性/干跑校验）；路由策略只读预览；Canary/Shadow 步进与 rollback/finalize；Registry 别名接管 + SOP-04 五命令触发卡
- **验收**：写操作先 Dry-Run；破坏性二次确认；Canary 步进 5→10→30→50→100 可选
- **依赖**：P2-3
- **设计映射**：【设计】§2.6、05 SOP-02/04

### Task P3-2 System Status 系统状态页 + 恢复中心
- 内容：三层健康自检一键执行 + 结果清单；节点/容器矩阵（NODE_ID）；依赖连通清单；挂接 dsv4-recover 五模式入口与根因矩阵
- **验收**：自检结果结构化可导出；WATCH 自愈开关状态过渡
- **依赖**：P0-3、P3-1
- **设计映射**：【设计】§2.8、05 §1/§6

### Task P3-3 布局智能记忆与自适应（智能②）
- 内容：看板布局/阈值/刷新间隔序列化落 IndexedDB；断点重排；异常高频面板提升开关
- **验收**：刷新与重开 100% 还原；schema 版本可迁移
- **依赖**：P2-1
- **设计映射**：【设计】§5.2

### Task P3-4 Cmd+K 快捷调用（智能③）
- 内容：全局命令面板；前端内存索引（页面/动作）；最近使用+高频快捷格；深链直达
- **验收**：Cmd+K 全站可用；可跳 `/live?metric=…`、`/logs?expr=…`
- **依赖**：P0-3
- **设计映射**：【设计】§5.3

### Task P3-5 操作路径提示引擎（智能⑤）
- 内容：本地 if-then 规则 + 近期操作学习；状态变体给出「下一步最佳动作」动作卡（如心跳丢失→建议 recover CHECKS）
- **验收**：关键状态变体命中建议且附直达按钮；标注「本地建议」非自动执行
- **依赖**：P3-2、P2-4
- **设计映射**：【设计】§5.5

### Task P3-6 性能门禁 + 验收清单闭环
- 内容：跑通【设计】§6.1 全 7 项自检；Lighthouse ≥90；对比 05 契约核对无虚构字段
- **验收**：性能自检全绿；八大页面五态完备；WS/SSE/轮询三态切换无断层
- **依赖**：全阶段
- **设计映射**：【设计】§6、§8.2

**P3 里程碑 M4 门禁**：七页全量、五维智能全量、通过性能门禁与验收清单。
