## 三、风险与注意

1. **Canary 行为变化（预期内）**：此前自动回退不存在（流量永滞留 canary），现回退真实生效——灰度模型再故障时流量将切回 baseline，属设计本意；恢复探测每退避间隔对每个 alias 发 1 次 max_tokens=1 请求（多 worker 重复，负载可忽略）。
2. **多 worker 重复恢复审计**：并发恢复可能产生重复 `canary.auto_recovered` 审计事件，同值覆写无害，已知可接受。
3. **环境隐患提醒（非本轮引入）**：本机 venv 混装 3.12/3.14 解释器（`.venv/bin/pip` 指向 3.14），装包须用 `.venv/bin/python -m pip`；建议择机构建干净 3.12 venv。
4. **工作区未提交**：本轮及前五轮改动均未 commit（工作区含大量非本次产生的变更），发布前请按白名单拣选提交：`core/api/{cache.py,main.py,middleware/rate_limit.py,services/document_processor.py,services/model_registry_svc.py,utils/cache.py,utils/metrics.py}`、`pytest.ini`、`requirements*.txt|lock`、`Dockerfile`、`.github/workflows/ci.yml`、`deploy/nas/prometheus.yml`、`deploy/nas/prometheus-rules/redis-down.rules.yml`、`scripts/chaos-redis.sh`、`tests/`（conftest + 8 个新测试文件）、`CHANGELOG.md`、本执行记录目录文档。
