# 【YYC3-101 模型下载虚拟环境 交接说明】

本次在 yyc3-101 节点 `yyc3-101-projects/models` 目录完成**独立隔离 Python 虚拟环境部署**，用于大模型权重拉取、模型校验、后续推理依赖管理，完全不污染系统原生 Python 环境。

## 1. 环境信息

- 节点：yyc3-101
- 工作目录：`yyc3-101-projects/models`
- 虚拟环境目录：`./venv-modelscope`
- 环境依赖：modelscope 最新稳定版，适配 GLM-5.3-Flash、Qwen 全系列、Embedding/Reranker 等全部模型下载

## 2. 环境激活方式（适配当前 sh/bash 双兼容）

```bash
cd yyc3-101-projects/models
. ./venv-modelscope/bin/activate
```

激活成功标识：终端前缀显示 `(venv-modelscope)`

## 3. 已安装核心能力

- 完整 modelscope 模型下载、断点续传、文件完整性校验
- 支持超大 FP8 模型稳定拉取（适配 DGX Spark GB10 硬件）
- 限制并行下载数、超时自动重试，适配大体积 safetensors 权重

## 4. 当前任务状态

- 正在后台拉取核心主模型：**GLM-5.3-Flash（FP8 328GB）**
- 采用低并发稳传策略，避免网络断连、文件损坏
- 所有模型统一落地当前 models 目录，与 yyc3-102 模型资产统一管理

## 5. 后续使用规范

1. 所有模型下载、更新、校验**必须进入该虚拟环境执行**
2. 禁止使用系统 `pip` 安装任何 AI 相关依赖，避免破坏 DGX 原生环境
3. 大模型下载统一使用 1–2 并发稳传模式，保障完整性
4. 新模型入库、存量模型校验，全部在此环境操作

## 6. 退出环境

```bash
deactivate
```
