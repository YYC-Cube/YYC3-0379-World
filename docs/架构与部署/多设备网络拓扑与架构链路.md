## 三、数据流 / 请求链路（全链路闭环）

```
① 公网请求 → api.0379.world (HTTPS 443)
② Traefik (yyc3-33) → rate-limit → security-headers → fail2ban 联动
③ Gateway API :8000 (主) → 认证 401 拦截 / 健康检查
④ 模型路由 → 智能调度（EWMA 延迟 + 错误率 + 负载）
        ├→ 本地推理: yyc3-101 vLLM :8000 (qwen3.6:35b-a3b)
        ├→ 备选推理: yyc3-102 vLLM :8000 (qwen3:32b)
        ├→ 本机推理: yyc3-22 Ollama :11434 (yyc3-family-coder)
        └→ 云端 API: DeepSeek / 智谱 GLM (备用)
⑤ 数据持久化 → PostgreSQL (yyc3-33 生产主库) + Redis 缓存
⑥ 存储回源 → NAS yyc3-45 (NFS / Volume1 模型仓库)
⑦ 可观测 → Prometheus + Grafana + Loki (yyc3-33, 待启动)
```
