### 1.3 A 预案执行 runbook（参数从现存容器 inspect 反查，待授权执行）

```bash
# ① N2 退役 8B rerank（释放 ~16G UMA；0.6B reranker 兜底）
ssh yyc3-n2 "docker stop yyc3-rerank8b && docker update --restart=no yyc3-rerank8b"

# ② N2 旗舰 worker 重建（清 ray session 残留；参数=dsv4-worker inspect 实录）
ssh yyc3-n2 "docker rm -f dsv4-worker && docker run -d --name dsv4-worker \
  --gpus all --ipc=private --shm-size=16g --restart unless-stopped \
  --entrypoint bash \
  -v /home/yyc3/dsv4_worker.sh:/w.sh \
  -v /home/yyc3/models/DeepSeek-V4-Flash:/model \
  -e NCCL_IB_HCA=mlx5_0 -e NCCL_NET_GDR_LEVEL=5 -e NCCL_SOCKET_IFNAME=enp1s0f0np0 \
  docker.m.daocloud.io/vllm/vllm-openai:nightly /w.sh"

# ③ 101 head 协同重启（清 /tmp/ray；参数=dsv4-head inspect 实录，NET=host）
ssh yyc3-101 "docker rm -f dsv4-head && docker run -d --name dsv4-head \
  --gpus all --network host --ipc=private --shm-size=16g --restart unless-stopped \
  --entrypoint bash \
  -v /home/yyc3/dsv4_head.sh:/h.sh \
  -v /home/yyc3/yyc3-101-projects/models/DeepSeek-V4-Flash:/model \
  -e NCCL_IB_HCA=mlx5_0 -e NCCL_NET_GDR_LEVEL=5 -e NCCL_SOCKET_IFNAME=enp1s0f0np0 \
  docker.m.daocloud.io/vllm/vllm-openai:nightly /h.sh"
# 注：head 脚本内已含 ray start --head + rm -rf /tmp/ray 如需彻底清残留，先 bash -c 'rm -rf /tmp/ray' 再 exec /h.sh

# ④ 终验（TB 权重冷加载 5–15min）
ssh yyc3-101 "curl -s -m 5 http://localhost:8001/health"        # vllm health 200
ssh yyc3-101 "curl -s -m 5 http://localhost:9103/v1/model/health" # 契约端点 healthy
curl -s -H "X-API-Key: <生产key>" https://api.0379.world/v1/models | grep deepseek-v4-flash
```

- 回滚：`docker start yyc3-rerank8b`（容器 stop 未删，秒级恢复）+ 旗舰维持停摆现状；
- 恢复后监控 N2 `available` 内存，若 <15G 需复评（8B emb 是否同判零增量）。
