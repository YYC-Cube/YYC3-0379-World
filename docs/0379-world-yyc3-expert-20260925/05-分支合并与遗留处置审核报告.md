- compose 重建 + **smoke-test.sh 部署后冒烟**（SMOKE_PASS/FAIL 日志——Phase 7 遗留观察「SMOKE_FAIL 3/5」即来自此链）；注释原话「smoke-test.sh 随 repo 分发」——**设计意图明确：部署文件经仓库分发**

### 3.2 风险判定

| 项 | 判定 |
| -- | ---- |
| 文件角色 | NAS cron 部署链的**仓库分发载体**（OPS-RECOVERY 铁律 1 的 `cd /Volume2/yyc3-33` 即同目录体系） |
