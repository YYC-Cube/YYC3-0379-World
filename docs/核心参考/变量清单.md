## 🌐 网关应用变量（模型注册中心，2026-09-28 新增；10-05 扩充）

> 规范锚点：`docs/模型接入与注册/02-Registry目标架构.md`；nas compose 经 `${VAR:-}` 逐条声明注入容器（b2c0c2d 修复语义）。

| 变量名 | 缺省值 | 现值（NAS 生产） | 说明 |
|--------|--------|------------------|------|
| `REGISTRY_ENABLED` | `false` | `true`（yyc3-45 .env） | 模型注册中心开关：true 启用 `/registry/v1/**` 写面 + startup 合并 + Phase B 事件消费者；false 完全旁路（纯 env 通道行为不变） |
| `REGISTRY_HEARTBEAT_TOKEN` | 空（跳过校验） | 已配置（48-hex，**10-05 生产启用**） | 心跳独立认证：请求头 `X-YYC3-Registry-Token`；未配置跳过（灰度兼容）/错值 401/正确 200；docker-compose.nas.yml 透传；防心跳伪造 |
| `ADMIN_API_KEYS` | — | 已配置 | 注册 Agent 复用（`--admin-key-env` 指定读取，注册/ready/心跳均为管理面操作） |
| `OPENAI_COMPATIBLE_UPSTREAMS` | `[]` | 7 上游 | env 通道（兜底）；与 Registry 双写共存，registry 条目 `registry-{model_id}` 命名隔离、priority 5 |

**注册 Agent 运行变量**（`core/scripts/model_register_agent.py`，算力节点侧 CLI 参数非 env；stdlib 零依赖）：
`--gateway`（网关基址）/ `--meta`（model-meta.json）/ `--admin-key-env`（缺省 ADMIN_API_KEYS）/ `--registry-token-env`（心跳 Token 读取的 env 名，缺省 REGISTRY_HEARTBEAT_TOKEN）/ `--interval`（心跳周期，缺省 30s）/ `--contract-port`（契约端点探活端口）/ `--set K=V`（元数据覆盖）。优雅退出：SIGTERM/SIGINT 触发 offline 心跳。

**代码常量**（非 env，`model_registry_svc.py`）：`yyc3:registry:events`（Redis 事件频道，SSE/Phase B 消费同源）；TTL 三级阶梯 90/180/300s；`yyc3:canary:{alias}`（灰度 hash，字段 baseline/canary/weight/shadow，10-05 新增）。
