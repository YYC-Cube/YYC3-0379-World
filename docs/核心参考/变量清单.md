```bash
# yyc3-22 PostgreSQL

DB_PORT=5433
DB_USER=yyc3_dev
```

## 📝 变量使用示例

### Python

```python
import os

# 读取环境变量
db_host = os.getenv('DB_HOST', 'localhost')
db_port = int(os.getenv('DB_PORT', '5433'))

# 使用变量
connection_string = f"postgresql://{db_host}:{db_port}/yyc3_mcp"
```

### Bash

```bash
#!/bin/bash

# 定义变量
DB_HOST="localhost"
DB_PORT="5433"
DB_USER="yyc3_dev"
DB_NAME="yyc3_mcp"

# 使用变量
psql -h $DB_HOST -p $DB_PORT -U $DB_USER -d $DB_NAME
```

### 配置文件

```yaml
database:
  host: ${DB_HOST:localhost}
  port: ${DB_PORT:5433}
  user: ${DB_USER:yyc3_dev}
  name: ${DB_NAME:yyc3_mcp}
```
