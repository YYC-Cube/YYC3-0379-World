## 模块职责

| 目录 | 职责 |
|------|------|
| `core/api/` | FastAPI 应用核心，API路由、服务、中间件 |
| `core/api/api/` | API端点定义（聊天、知识库、RAG、MCP、WebSocket） |
| `core/api/services/` | Provider集成层（智谱/OpenAI/DeepSeek/Ollama）+ 路由 + RAG |
| `core/api/middleware/` | 认证、限流、API版本管理 |
| `core/api/utils/` | 缓存、并发、加密、日志、监控工具 |
| `core/config/` | 所有基础设施配置（Docker/Nginx/Redis/VPN等） |
| `deploy/` | 高可用部署编排（四机双活） |
| `docs/` | 项目文档（Diátaxis分类：教程/指南/参考/解析） |
| `scripts/` | 运维和部署脚本 |
| `scripts/tools/` | 代码规范检查和自动修复工具 |
| `tests/` | 单元测试、E2E测试、性能测试 |
