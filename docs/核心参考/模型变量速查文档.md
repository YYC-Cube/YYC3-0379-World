## 四、上游池变量（NAS `.env` `OPENAI_COMPATIBLE_UPSTREAMS` 现役值）

```json
[
 {"name":"flagship-svl2","base_url":"http://100.65.64.49:8888","models":["nemotron-3.5-super-vl","super-vl*"],"priority":1,"weight":100,"capacity":8},
 {"name":"embed-nim-bge-m3","base_url":"http://100.98.206.18:11434","models":["baai/bge-m3","bge-m3","*"],"capability":"embedding","priority":2},
 {"name":"rerank-nim-bge","base_url":"http://100.98.206.18:11434","models":["baai/bge-reranker-v2-m3","bge-reranker-v2-m3","*"],"capability":"rerank","priority":3,"cap_paths":{"rerank":"/v1/ranking"}},
 {"name":"coder-77","base_url":"http://100.98.206.18:11434","models":["qwen3-coder-30b"],"priority":2,"capacity":8},
 {"name":"mac-mlx","base_url":"http://100.87.159.21:11435","models":["family-coder"],"priority":4,"capacity":4}
]
```

> **URL 拼接规则**：`base_url + /v1/chat/completions`（网关自动补 `/v1`，`base_url` **不带** `/v1`）。
> **修改通道**：`PUT /v1/admin/upstreams/{name}`（管理 Key，双写 .env 免重启）或改 `.env` 后重建网关。

## 五、服务端行为变量（网关侧）

| 变量 | 现值 | 语义 |
|---|---|---|
| `ROUTER_ENABLED` | `true` | 上游池路由开关 |
| `UPSTREAM_THINKING_OFF` | `true`（默认，PR #53） | 上游 chat 注入 `enable_thinking:false` |
| `LOCAL_DGX_MAX_TOKENS` | `1024` | 网关硬顶；请求头 `x-llm-profile: long` → 4096 |
| `ADMIN_API_KEYS` | `sk-admin-…`（已配） | 管理面独立密钥（与业务 Key 分离） |
| `A2A_RESULT_CONSUMER_ENABLED` | 建议 `false` | 八家臣退役后消 Redis 告警风暴 |
