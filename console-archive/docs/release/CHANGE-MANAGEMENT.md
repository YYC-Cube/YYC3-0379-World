# 变更分级与审批矩阵 — YYC³ Token Console（S20）

> 原则：**分级决定门禁与审批强度**；所有变更走 Conventional Commits + 标签（类型+模块必选）；
> main 受保护禁 force-push；分级存疑时就高不就低。

## 分级矩阵

| 级别 | 定义 | 示例（本仓实录） | 审批 | 门禁 | 回滚要求 |
| --- | --- | --- | --- | --- | --- |
| **C0** 文档/注释 | 零运行时影响 | README 修正（02a62da）/ 本批 ADR / 审计归档 | 自查 | build 不需；mermaid 闸（涉图表时） | git revert |
| **C1** 非功能性 | 行为不变 | 色值 tokens 迁移五片 / S2 类型修复 / 重构拆分 | 1 人（评审） | 全量门禁（12 命令）+ 行数/断言语义不变证明 | git revert（断言零改动是前提） |
| **C2** 功能性 | 可观察行为变化 | jti 吊销 + 审计 JSONL（8e016f8）/ settings 内容协商（dc9b808）/ gpuUtil 聚合（89d91b4） | 2 人 | 全量 + e2e + **部署单端实测后推广**（NAS→ECS 判例） | 回滚剧本 + 双端同步说明 |
| **C3** 架构性 | 依赖/边界/契约/门禁 | 双旗标落地（bf40112）/ lint:fp+dup 门禁（afb077d）/ lib/http.ts 收敛 / gitleaks 豁免（136fbec） | 架构师 | 全量 + **ADR（一决策一文件）** + 元门禁探针（新规则必附 FP 评估与探针） | ADR 回滚路径章节 |
| **C4** 破坏性 | 删 API / 改契约 / 数据迁移 | （历史）/users 路由归档 / 后端 007 迁移 | 架构师 + 发布官 | 全量 + 迁移说明 + **回滚演练（沙箱实测）** + git 历史留档 | 演练过的回滚剧本 |

## 分级判定流程

```
改动是否触碰 deploy/*.mjs 或 types/ 契约或门禁配置？
├─ 是 → 是否删除/改写既有对外语义？
│        ├─ 是 → C4
│        └─ 否 → C3（须 ADR）
├─ 否 → 用户可观察行为是否变化？
│        ├─ 是 → C2
│        └─ 否 → 触碰运行时代码？是→C1 / 否（纯文档）→C0
```

## 审批与执行者

| 级别 | 执行 | 评审 | 发布窗口 |
| --- | --- | --- | --- |
| C0 | 任何人 | 自查 | 任意 |
| C1 | 开发者 | 1 人 PR 评审 | 任意 |
| C2 | 开发者 | 2 人 + 部署实测单端 | 工作时间（避开周五下午） |
| C3 | 资深开发者 | 架构师 | 预约窗口 + 审计期冻结检查 |
| C4 | 发布官主导 | 架构师+发布官双人 | 预约窗口 + 维护公告 |

## 特例映射

- **服务端部署件（deploy/*.mjs）**：按 C2 起步（触鉴权/代理语义自动升 C3）；发布 = scp 四件 + 三端同步（NAS/ECS 判例：单端先行的修复必须在 backlog 登记推广时限——L-01 教训）。
- **基线 JSON（color/dup/size/knip）**：下调=C1（附迁移证据）；上调=C4（红线禁止，除非大规模删除代码）。
- **gitleaks/ast-grep 豁免条目**：C3（附原因+复核日期+Fingerprint）。
- **CI 工作流**：C3（ci.yml 是门禁自身的载体）。
